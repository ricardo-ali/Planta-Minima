# Planta Minima

Distribucion portable compilada para Windows 11 x64. Sin codigo fuente, modelos ni datos de plantas.

Descargar el ZIP de [Releases](https://github.com/ricardo-ali/Planta-Minima/releases/latest), extraerlo completo y abrir MaquetaVisor.exe.

Actualizar desde Opciones > General > Buscar actualizacion. Instala por usuario y avisa para reiniciar la app.
